## Full LinkedIn Post / Project Description

🚀 **Excited to share Campus Vault — an AI-powered academic certificate verification system I built for KTU students!**

📌 **The Problem:**
Managing student activity certificates at Kerala Technological University is a tedious manual process. Students submit physical documents, teachers spend hours reviewing them, and errors — including fraudulent submissions — slip through.

💡 **The Solution: Campus Vault**
A full-stack web application that automates the entire certificate lifecycle using **Google Gemini AI**.

Here's what it does:

🤖 **AI-Powered Analysis**
- Students upload certificates (JPEG, PNG, PDF)
- Google Gemini Flash analyzes the document, extracts event details, determines activity level, predicts KTU activity points, and flags suspicious or fraudulent documents — all in under 5 seconds

🛡️ **Fraud Detection**
- Multi-layer verification based on KTU rulebook: checks for tampered documents, mismatched fonts, non-certificate images, and unrealistic point claims
- Risk levels: **LOW / HIGH / INVALID** with manual override for teachers

👨‍🏫 **Teacher Dashboard**
- Centralized review console for all pending submissions
- One-click approve/reject with automatic student notifications
- Visual fraud risk indicators to prioritize manual reviews

🔔 **Real-Time Notifications**
- Students receive instant alerts on approval or rejection
- Teachers get notified when new submissions arrive
- Email confirmations via Resend API

🛠️ **Tech Stack:**
- **Frontend:** React 18, Vite, Tailwind CSS, Axios
- **Backend:** Node.js, Express.js, MongoDB, Mongoose
- **AI:** Google Gemini Flash (Generative AI SDK)
- **Auth:** JWT-based role authentication (Student / Teacher)
- **Email:** Resend API
- **Design:** Glassmorphic UI with neon accents

📈 **Impact:**
- Reduces certificate verification time from days to seconds
- Deters academic fraud with AI-assisted detection
- Transparent audit trail for all submissions
- Scalable for any university running KTU-style activity point systems
